Auth for LiteLLM

If you set LITELLM_MASTER_KEY, browsers need a header. Example:

curl http://localhost:4000/v1/models \
  -H "Authorization: Bearer sk-aether-local"

Leave the key empty in .env for open local lab access (not for the public internet).
